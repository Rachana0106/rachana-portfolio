## Run Locally

Clone the repository:

```bash
git clone https://github.com/Rachana0106/rachana-portfolio.git
```

Open the project folder:

```bash
cd rachana-portfolio
```

Then open `index.html` in your browser or run it using the VS Code Live Server extension.

## Important Fixes

Before presenting the project professionally, fix these issues:

### Incorrect closing tag

Replace:

```html
</section>>
```

With:

```html
</section>
```

### Remove accidental backticks

Delete the triple backticks placed inside `index.html` after the Projects section.

### Fix the Weather Mood link

The Weather Mood button is labelled as a live demo, but it links to the repository. Either enable GitHub Pages or rename the button to:

```text
View Repository
```

### Update your main title


With:
